# Product Requirements Document: Neobrutalism Portfolio Landing Page

## Project Overview
**Project Name:** Neobrutalism Web Portfolio  
**Type:** Static single-page portfolio landing page  
**Timeline:** 3 days  
**Tech Stack:** HTML, CSS, Vanilla JavaScript  

## Problem Statement
School assignment requires a personal portfolio landing page. Standard student portfolios use generic templates (pastel colors, soft shadows, template-y designs). Need visually striking alternative that demonstrates technical skill and design awareness while remaining readable for non-designer audience.

## Target Audience
- **Primary:** Guru (grading assignment - technical correctness + creativity)
- **Secondary:** Peers (validation/impression - "beda dari yang lain")

## Success Criteria
1. **Grade Target:** Minimum B+/A- from teacher evaluation
2. **Peer Validation:** 2-3 classmates comment "keren/beda/impressive"
3. **Visual Identity:** Unmistakably neobrutalism aesthetic (not halfway/generic)
   - Thick black borders (2-4px)
   - Flat bright colors (yellow, pink, cyan, lime)
   - Heavy drop shadows for depth
   - High contrast, playful but readable

### Visual Design System (Neobrutalism)
- **Borders:** 2-4px solid black on all major elements
- **Colors:** Flat bright palette - yellow (#FFD700 range), pink (#FF69B4 range), cyan (#00FFFF range), lime (#32CD32 range)
- **Shadows:** Heavy drop shadows (4-8px offset, solid color, no blur)
- **Typography:** Bold sans-serif for headers, readable sans-serif for body
- **Layout:** Organic placement (not rigid grid), slight rotation OK for personality
- **Backgrounds:** Solid colors, no gradients
- **Corners:** Sharp or slightly rounded (0-8px max)

## Technical Constraints
- **Format:** Single-page static HTML
- **No frameworks:** Pure HTML+CSS+vanilla JS only
- **Responsive:** Must work on mobile + desktop
- **Hosting:** GitHub Pages compatible (static deployment)
- **Browser:** Modern browsers (Chrome, Firefox, Safari latest)

## Out of Scope
- ❌ Contact form (backend/submission)
- ❌ Blog/article section
- ❌ Dark mode toggle
- ❌ Complex animations (GSAP, heavy transitions)
- ❌ CMS/backend integration
- ❌ Multi-language support
- ❌ Project showcase (no projects yet)

## Deliverables
1. `index.html` - Single page structure
2. `style.css` - Neobrutalism styling
3. `script.js` - Minimal interactions (if needed)
4. `assets/` - Profile photo, any icons
5. `README.md` - Setup/deployment instructions

## Quality Gates
- [ ] Responsive on mobile (320px) to desktop (1920px)
- [ ] All links functional (open in new tab)
- [ ] Photo optimized (fast load)
- [ ] No console errors
- [ ] Clean semantic HTML
- [ ] Visual unmistakably neobrutalism (validated against reference)
- [ ] Readable text contrast (WCAG AA minimum)

## Timeline Breakdown (3 days)
- **Day 1:** Structure HTML + base CSS + color system
- **Day 2:** Neobrutalism styling (borders, shadows, layout) + content
- **Day 3:** Responsive polish + testing + deployment

## References
- Neobrutalism characteristics: thick borders, flat colors, heavy shadows, playful organic layout
- NOT industrial brutalism (Swiss print/military terminal - different aesthetic)
